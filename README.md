# Trekking_Management_Application

This project ia about to design and build a centralized management application that allows administrators, guides and trekkers to schedule, coordinate, and process trekking activities seamlessly eliminating double-bookings and scheduling conflicts. 


For this application I have used -
Flask (Python 3.14) : Core web framework handling application routing, logic, sessions, and request dispatching.

Flask-SQLAlchemy : ORM mapper to interact with the SQLite relational database using
object-oriented Python classes. SQLite Self-contained relational database used for local data persistence and storing application records.

Jinja2 Templates : Server-side templating engine utilized to dynamically render responsive
HTML pages.

Bootstrap 5 / CSS : Responsive front-end styling library to design clean modern grid layouts and responsive components.

Werkzeug Security : Used for password security, specifically generating and validating secure password hashes.

os (Standard Library) : Built-in Python module utilized for filesystem operations, database folder initialization, and managing paths.
